# Getting support

## Documentation first

The full documentation, including per-tree guides and tutorials, is at
[forest.beiwe.org](https://forest.beiwe.org/en/latest/). The
[README](README.md) covers installation and a worked end-to-end example using synthetic data.

## Questions and problems

- **Something is broken.** Open an
  [issue](https://github.com/onnela-lab/forest/issues) using the bug report template.
  Include your Python version, your Forest version, and a minimal reproducible example.
- **A question about how to use Forest.** Open an
  [issue](https://github.com/onnela-lab/forest/issues) and describe what you are trying to
  compute and what you have tried. There is no separate discussion forum at present, so
  questions belong in the issue tracker.
- **A question about the statistical methods.** The methods implemented in Forest are
  published separately. The README and the per-tree documentation link the relevant papers,
  which are the best reference for what a method assumes and when it applies.
- **A question about data collection rather than analysis.** Forest analyzes data collected
  by the Beiwe platform. Questions about collection, deployment, or the study portal belong
  in the [beiwe-backend](https://github.com/onnela-lab/beiwe-backend) repository.

## Response times

Forest is maintained by a small academic research group. We aim to respond to issues, but
response times vary with teaching and grant cycles. Issues that include a reproducible
example are substantially faster to resolve.
