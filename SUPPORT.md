# Getting support

## Documentation first

The full documentation, including per-tree guides and tutorials, is at
[forest.beiwe.org](https://forest.beiwe.org/en/latest/). The [README](README.md) covers installation
and a worked end-to-end example using our synthetic data generation.

## Questions and problems

- **Something is broken.**
  - First, test on the development version of Forest by following the directions in the
    [README](README.md).
  - Search the [issue tracker](https://github.com/onnela-lab/forest/issues) for related issues,
    including the _pinned issues_.
  - If you find one, please comment on it. Problems that many people run into get our attention
    first, and you may be able to help the original poster.
  - If you cannot find one, open a new issue using the bug report template.
  - A short example that we can copy, paste and run is the fastest way to get your problem resolved.

- **A question about how to use Forest.** Open an
  [issue](https://github.com/onnela-lab/forest/issues) and describe what you are trying to compute
  and what you have tried. If the documentation was missing something you needed, tell us so that we
  can update it for the next person.

- **A question about the statistical methods.** The methods in Forest are published separately, and
  the documentation page for each tree links the relevant papers. They are the best reference for
  what a method assumes and when it applies. When you write to us, please keep your summary
  accessible, since people at Onnela Lab range from students to senior researchers and have varying
  technical and mathematical backgrounds. The original author of a method may also have moved on and
  no longer be directly associated with the lab.

- **A question about data collection rather than analysis.** Forest analyzes data collected by the
  Beiwe Platform. Questions about collection, deployment, or the study portal website should be
  directed to the [beiwe-backend](https://github.com/onnela-lab/beiwe-backend) repository.

- **LLM- or AI-generated posts.** Please edit any LLM output before you post it, including in code
  and code comments. Trim it down and put it in context for us. Unedited LLM text creates extra work
  for the maintainers, and we may ignore or delete posts that have not been edited.

## Response times

Forest is maintained by a small academic research group. We try to respond to issues, but response
times vary with teaching and grant cycles.
