# Getting support

## Documentation first

The full documentation, including per-tree guides and tutorials, is at
[forest.beiwe.org](https://forest.beiwe.org/en/latest/). The [README](README.md) covers installation
and a worked end-to-end example using our synthetic data generation.

## Questions and problems

- **Something is broken.**
  - Please first test on the development version of Forest by following the directions in the ReadMe. 
  - Go to [issue](https://github.com/onnela-lab/forest/issues), and (briefly) search for related items.
  - Check _pinned issues_ in particular.
  - If you find a related issue, **please comment!** Our attention is democratic.
  - See if you can help the original poster, they may be able to help you.
  - If you can't find an issue you can create a new one using the bug report template.
  - Providing an easy, copy-and-pasteable example of your issue is the fastest way to get it resolved.
  
- **A question about how to use Forest.** Open an
  [issue](https://github.com/onnela-lab/forest/issues) and describe what you are trying to compute
  and what you have tried. Please inform us where any documentation is lacking so that we can update
  it for future users encountering similar difficulties.

- **A question about the statistical methods.** The methods implemented in Forest are published
  separately, and the per-tree documentation pages link the relevant papers, which are the best
  reference for what a method assumes and when it applies. Try to pitch your summary toward the
  simpler end of the spectrum, individuals currently at Onnela Lab can include students and
  researchers, who all have varying levels of technical and mathematical expertise. We are an
  academic organization and the original author may have moved on and no longer be directly
  associated with Onnela Lab.

- **A question about data collection rather than analysis.** Forest analyzes data collected by the
  Beiwe Platform. Questions about collection, deployment, or the study portal website should be
  directed to the [beiwe-backend](https://github.com/onnela-lab/beiwe-backend) repository.

- **LLM/AI-generated posts.**
  Software development already includes managing LLM verbosity, cutting it down and
  recontextualizing their output. Please moderate the output of LLMs present in your posts,
  _including in code and code comments._ We need you to spend time on that effort, otherwise it
  creates creates additional work for us. The maintainers of Forest may ignore or delete poorly
  moderated LLM/AI-generated posts.


## Response times

Forest is maintained by a small academic research group. We try to respond to issues, but response
times vary with teaching and grant cycles.
